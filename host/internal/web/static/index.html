任务

点列表右侧的竖向圆点（或上下拖动屏幕）翻任务页。打开「性能」插件后，用量上方的一条显示这台电脑的读数，一次三个，多的每 6 秒轮换一组。

设备状态

下发数据

发给屏幕的 snapshot 消息，格式见 docs/protocol-v1.md。


          

          

            
读数条数据

            
发给屏幕的 line 消息（§3.5），紧跟每条 snapshot 发送，读数变了才重发；没有开插件时是空列表。

            

          

        

      

    


    

      
安装后，Claude Code 和 Codex 会在状态变化时立即通知 go-dock。修改前会自动备份原文件（*.go-dock-时间.bak），卸载可恢复。

      

    


    

      
插件的读数显示在屏幕 Agent 页用量上方的一条里；「设备预览」里看到的和屏幕上一样。

      

        

          
性能

          
        

        

          
          显示运行 go-dock 的这台电脑的 CPU、GPU、内存、风扇、温度和磁盘，每 2 秒读一次，只在开启时读取。温度是芯片最热处的温度（Apple 芯片的 Mac 上是整块芯片，其他电脑是 CPU）。一次显示三个，多的每 6 秒向左轮换一组；偏高时变琥珀色或红色（温度从 85°C、95°C 起）。Mac 上内存和「活动监视器」的「已使用内存」一样算（App 内存 + 联动 + 被压缩），颜色跟着内存压力变。读不到的项不显示：Windows 读不到风扇和温度，GPU 只支持 Mac 和 NVIDIA 显卡（Linux 上还有 AMD）。
