安装后，Claude Code 和 Codex 会在状态变化时立即通知 go-dock。修改前会自动备份原文件（*.go-dock-时间.bak），卸载可恢复。

      

    


    

      
插件显示在屏幕上 Agent 页右边的功能页里，左右滑动切换；在「设备预览」里也能直接操作。灯光通过 MQTT 控制，go-dock 负责连接 broker（可以有多个），屏幕本身不联网；空调用屏幕外接的红外模块控制；性能页显示这台电脑的 CPU、GPU、内存等读数。

      

        

          
MQTT broker

          
        

        

          每个 broker 一条连接，灯光等插件按名字选用。地址支持 mqtt://、mqtts://（TLS）、ws://、wss://；只填主机和端口时按 mqtt:// 处理，省略端口时用 1883 / 8883。密码保存在本机的 go-dock 配置文件里。
          

          

            
            最多 8 个
          

        

        

          
          
        

      

      

        

          
灯光

          
        

        

          
          每盏灯填一个命令主题和开 / 关时发送的内容；填了状态主题，屏幕显示的是灯实际回报的状态，否则按最后一次命令显示。状态是 JSON 时，「状态字段」填要读的字段，多层用点号连起来（如 params.Onoff），JSON 里的 true / false 直接识别。状态值不区分大小写；不填时，有状态字段默认 ON / OFF，没有则与开灯、关灯时发送的内容相同。
          

          

            
            最多 6 盏
          

        

        

          
          
        

      

      

        

          
空调

          
        

        

          
          屏幕外接红外发射模块，像遥控器一样控制格力空调；再接一个红外接收模块，用原装遥控器调过的设定也会同步到屏幕上。红外是单向的，空调不会回报状态，页面显示的是最后一次发出或收到的设定。接线见固件说明「红外遥控（空调）」。

性能

          
        

        

          
          显示运行 go-dock 的这台电脑的 CPU、GPU、内存、风扇、网络和磁盘，每 2 秒读一次，图表是最近一分钟。Mac 上内存和「活动监视器」的「已使用内存」一样算（App 内存 + 联动 + 被压缩），卡片颜色跟着内存压力变，内存紧张时页面顶上会提示。读不到的项不显示：Windows 读不到风扇，GPU 只支持 Mac 和 NVIDIA 显卡（Linux 上还有 AMD）。只在开启时读取。
          上面两张是大卡片（图表 + 明细），下面是小卡片。在屏幕上或「设备预览」里按住一张卡片约半秒，拖到另一张上松手，两张就交换位置；排列会保存下来。
